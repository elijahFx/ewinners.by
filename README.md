# E-Winners (React)

Точная React-копия сайта [ewinners.by](http://ewinners.by): главная, колл-центр, HR, маркетинг и страница входа.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Стек

- React 19 + Vite
- React Router
- Lucide icons
- Оригинальные стили и ассеты с ewinners.by
