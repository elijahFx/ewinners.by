# E-Winners — личный кабинет и админка

Платформа для учёта баланса клиентов call-центра / CRM: счета, документы, операции, API-ключи и банковский контроль.

```
ewinners.by/
  ewinners.by/   # фронтенд (React + Vite) → Netlify
  server/        # бэкенд (Express + MySQL)
```

---

## Быстрый старт

### Фронтенд

```bash
cd ewinners.by
npm install
npm run dev        # локально
npm run build      # прод-сборка
```

Переменная `VITE_API_URL` — адрес API (по умолчанию прод/стенд).

### Бэкенд

```bash
cd server
cp .env.example .env   # если есть пример; иначе заполните .env
npm install
npm run migrate
npm run seed           # справочники + админ eadmin
npm start
```

Полезные команды:

| Команда | Назначение |
|--------|------------|
| `npm run migrate` | Миграции БД |
| `npm run seed` | Услуги, тарифы, админ `eadmin` |
| `npm run reset:handoff` | Очистка пользователей/клиентов + админ `eadmin` |
| `npm run create:techadmin` | Аккаунт `techadmin` |

Админ по умолчанию после seed / reset:

- логин: `eadmin`
- пароль: `tobeornottobe2077`

Технический админ:

```bash
npm run create:techadmin
```

- логин: `techadmin`
- пароль: `tobeornottobe2001`

## Роли

| Роль | Кто это | Что может |
|------|---------|-----------|
| **admin** | Администратор | Всё: клиенты, пользователи, счета, банкинг, корректировки |
| **accountant** | Бухгалтер | Счета, банкинг, корректировки, просмотр |
| **client** | Клиент | Свой кабинет: баланс, счета, документы, операции, CRM |

## Как работать администратору

### 1. Создать компанию (организацию)

1. Войти как admin / accountant.
2. Раздел **Клиенты** (`/cabinet/admin/companies`).
3. Создать компанию: название, УНП, адрес, банк, IBAN, БИК и т.д.

Организации создаёт **только админ**. Клиент сам их добавить не может.

### 2. Создать пользователя-клиента

1. Раздел **Пользователи**.
2. **Добавить**: email, ФИО, роль `client`.
3. Можно сразу указать основную организацию.
4. Режим пароля: приглашение на email / автопароль / ручной.

### 3. Привязать несколько организаций к одному пользователю

1. В таблице пользователей у клиента нажать **Орг.**
2. Выбрать компанию из списка (сначала создайте её в **Клиенты**).
3. **Привязать**.
4. При необходимости привяжите ещё компании.
5. **Отвязать** — убрать доступ к организации.

В кабинете клиента в сайдбаре появится переключатель **Организация**. Баланс, счета и документы относятся к **активной** организации.

### 4. Счета клиентов

Раздел **Счета** (`/cabinet/admin/invoices`):

- все счета всех организаций;
- просмотр / скачивание PDF;
- кнопка **Оплачен** — отмечает счёт оплаченным и **зачисляет сумму на баланс** клиента, после чего формируется акт.

### 5. Банкинг

Раздел **Банкинг** — поступления / списания / выписка из Priorbank API (нужна настройка env).

### 6. Корректировки баланса

Раздел **Корректировки** — ручное зачисление / списание с комментарием (без привязки к счёту).

### 7. API-ключи CRM

Раздел **API-ключи** — ключи компаний для интеграции CRM. Клиент также может сгенерировать ключ у себя в **Интеграция CRM**.

## Как пользоваться кабинетом клиента

1. Войти по логину (email / логин) и паролю.
2. Если организаций несколько — выбрать нужную в сайдбаре.
3. Основные разделы:

| Раздел | Назначение |
|--------|------------|
| **Обзор** | Баланс, краткая сводка |
| **Операции** | История списаний / пополнений, экспорт в Excel |
| **Счета** | Создать счёт на пополнение, скачать PDF |
| **Документы** | Счета, акты, детализация; «Сформировать детализацию» |
| **Тарифы** | Актуальные тарифы |
| **Организации** | Просмотр и переключение (без создания) |
| **Уведомления** | Email / Telegram |
| **Интеграция CRM** | API-ключ и документация endpoints |

### Пополнение баланса

1. **Счета** → указать сумму → сформировать PDF.
2. Оплатить по реквизитам.
3. Админ в **Счета** отмечает счёт **Оплачен** → баланс увеличивается, появляется акт.

### Детализация

В **Документы** → **Сформировать детализацию**.  
За один календарный месяц одна детализация: повторное нажатие **обновляет** тот же PDF (на экране будет сообщение). Если списаний не было — документ с суммой 0.00.

## Типовой сценарий «с нуля»

1. Админ создаёт компанию в **Клиенты**.
2. Админ создаёт пользователя `client` в **Пользователи**.
3. Админ жмёт **Орг.** у пользователя и привязывает одну или несколько компаний.
4. Клиент входит, выбирает организацию, выставляет счёт.
5. Админ подтверждает оплату счёта → клиент тратит баланс через CRM / тарифы.

## Структура проекта

- `ewinners.by/src/cabinet/` — UI кабинета
- `server/src/routes/` — API (`auth`, `cabinet`, `admin`, `crm`, `lookup`)
- `server/src/services/` — PDF, биллинг, Priorbank, почта, Telegram 2FA

## Замечания по продакшену

- Заполните `.env` сервера: БД, JWT, SMTP, реквизиты компании для счетов, при необходимости Priorbank и Telegram.
- Шрифт с кириллицей для PDF: `server/assets/fonts/ArialUnicode.ttf` (или DejaVu).
- После деплоя бэкенда перезапустите Node-процесс, чтобы подтянуть новые маршруты.
